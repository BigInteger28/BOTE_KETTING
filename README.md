Met dit programma maak je een nieuwe groep engines in een level die het beste scoren tegen engines 1-2 levels lager. De nieuwe engines worden in ketting_engines.txt geplaatst en hun rating in bote.txt  
Input: Engines level 74-75  
Output: Engines die het goed doen worden als level 76 engines gemaakt (standaard 13 engines)  
Je kan kiezen welke beginzet er gespeeld wordt en welke diepte er moet vermeden worden indien nodig
